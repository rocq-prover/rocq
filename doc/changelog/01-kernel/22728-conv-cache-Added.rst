- **Added:**

  can be controlled with the flag :flag:`Kernel Conversion Cache`.
  The cache stores both positive and negative conversion results.
  (`#22728 <https://github.com/rocq-prover/rocq/pull/22728>`_,
  by Gaspar Ricci, reorganizing code proposed by Valerii Huhnin, Jason Gross and
  Pierre-Marie Pedrot).
